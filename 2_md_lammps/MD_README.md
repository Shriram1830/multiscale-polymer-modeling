# Molecular Dynamics Modeling of PEK (Crystalline and Amorphous Phases)

This is the second stage of the DFT → MD → micromechanics pipeline. It predicts the elastic constants of the crystalline and amorphous phases of PEK independently, using classical molecular dynamics in LAMMPS with the Class II PCFF-IFF force field. The two phase-level stiffness tensors produced here are the inputs to the micromechanics homogenization in `3_micromechanics_fea_ansys/`.

As with the rest of this repository, the files here are a vanilla template. Force field assignment, ensemble settings, and deformation protocols reflect a reasonable simulation procedure, but any specific numerical outcome (equilibrium density, moduli, Poisson's ratios, etc.) belongs to a specific production run and is not reproduced here.

## Repository Structure

    ├── equilibration.in   # energy minimization + NVT/NPT equilibration
    ├── tensile.in         # uniaxial tensile deformation, x/y/z
    ├── triclinic.in       # orthogonal -> triclinic box conversion
    └── shear.in           # shear deformation, xy/xz/yz

    md_amorphous/
    └── equilibration.in   # energy minimization + NVT/NPT equilibration
    

## Crystalline Phase Workflow

1. **Structure building (external tools)** — a single orthorhombic unit cell (46 atoms, two PEK monomers) is built in Avogadro from an isolated repeat unit, visualized in VESTA using the lattice parameters from Stage 1, and bond-corrected in OVITO to remove erroneous automated connectivity. The unit cell is used directly, not replicated into a supercell, because LAMMPS's `replicate` command does not propagate covalent bonds across periodic images — periodicity is instead enforced entirely through periodic boundary conditions on the single cell.

2. **Force field parameterization (LUNAR toolkit)** — the `atom_typing` module assigns PCFF-IFF atom types by graph-theoretic analysis of local bonding environments, distinguishing aromatic carbons, ether oxygen, carbonyl carbon, and carbonyl oxygen. The `all2lmp` module then generates the full LAMMPS data file with the Class II PCFF-IFF force field, including anharmonic bond, angle, dihedral, and improper terms and all cross-coupling terms.

3. **Equilibration** (`equilibration.in`) — energy minimization (conjugate gradient) to remove residual steric strain, followed by NVT equilibration at a target temperature and then NPT equilibration with isotropic pressure coupling, using a Nosé-Hoover thermostat/barostat. Multiple independent replicates are generated by assigning different initial velocity seeds.

4. **Tensile testing** (`tensile.in`) — uniaxial deformation applied independently along x, y, and z via `fix deform` at a constant engineering strain rate, under an NPT ensemble with lateral pressure held constant to allow Poisson contraction. The virial stress tensor is block-averaged via `fix ave/time` to suppress thermal noise. Young's modulus and Poisson's ratio are extracted downstream by `4_data_analysis/crystalline_tensile_properties.py` via linear regression over a specified elastic strain window.

5. **Triclinic conversion** (`triclinic.in`) — converts the equilibrated orthogonal box to a triclinic representation via `change_box`, then re-equilibrates under anisotropic NPT to relieve stresses introduced by the box transformation. Required before shear deformation can be applied.

6. **Shear testing** (`shear.in`) — shear deformation applied in each of the three principal planes (xy, xz, yz) via `fix deform` at the same strain rate and timestep as the tensile runs. Uses a `temp/deform`-based temperature compute so the NPT thermostat correctly excludes the streaming velocity introduced by the shear deformation. Shear modulus is extracted downstream by `4_data_analysis/crystalline_shear_properties.py`.

The three tensile moduli, three shear moduli, and Poisson's ratios from transverse strain response together assemble the full orthotropic elastic stiffness tensor for the crystalline phase, consistent with the known symmetry of the Pbcn space group.

## Amorphous Phase Workflow

The amorphous phase follows a workflow parallel to the crystalline one, with an added in-situ reactive polymerization stage since the amorphous phase represents a continuous, entangled polymer network rather than a fixed crystal lattice:

1. **Structure building** — the PEK repeat unit is built in Avogadro and geometry-optimized to remove steric clashes, the same as the crystalline monomer.

2. **Force field parameterization (LUNAR toolkit)** — `atom_typing` and `all2lmp` assign PCFF-IFF atom types and generate the LAMMPS topology, as for the crystalline phase. Pre- and post-reaction monomer templates are additionally processed through `bond_react_merge` to establish the atom mapping needed for reactive MD, and `cell_builder` packs the pre-reaction monomers randomly into a low-density periodic box.

3. **Densification and annealing** — the low-density packed system is compressed under NVT via a gradually applied `fix deform`, then annealed under NPT by heating and cooling back to the target temperature to relieve residual packing stresses.

4. **Reactive polymerization** — `fix bond/react` forms covalent bonds dynamically between designated reactive sites within a cutoff distance, run under NVT at an elevated temperature to increase chain mobility. The cross-linked network is then relaxed under NPT at the same elevated temperature, followed by a final equilibration at the target temperature under anisotropic pressure control to reach an isotropic amorphous morphology.

5. **Equilibration** (`equilibration.in`) — same minimization/NVT/NPT structure as the crystalline phase, applied post-polymerization. Multiple independent replicates are generated for statistical sampling.

6. **Tensile testing** (`tensile.in`) — uniaxial deformation applied independently along x, y, and z, identical in structure to the crystalline tensile protocol. Because the amorphous phase is macroscopically isotropic, the directional Poisson's ratios from all three loading axes are averaged into a single representative value per replicate downstream, by `4_data_analysis/amorphous_properties.py`. No shear or triclinic step is needed for the amorphous phase.

## Naming Convention

Output filenames follow `{phase}_seed{n}_{test}_{axis}.{ext}`, where `phase` is `crystalline` or `amorphous`. Each script's output is named to match what the next script in the pipeline expects as input:

    crystalline_seed1_equilibrated.data   <- equilibration.in (md_crystalline)
    crystalline_seed1_triclinic.data      <- triclinic.in
    crystalline_seed1_tension_X.log       <- tensile.in (md_crystalline)
    crystalline_seed1_shear_XY.log        <- shear.in
    amorphous_seed1_equilibrated.data     <- equilibration.in (md_amorphous)
    amorphous_seed1_tension_X.log         <- tensile.in (md_amorphous)

## Tools Used

- **Avogadro, VESTA, OVITO** — structure building and inspection.
- **LUNAR toolkit** — force field atom typing, LAMMPS data file generation, and reactive bond mapping for the amorphous phase.
- **LAMMPS** — all molecular dynamics simulation, using the Class II PCFF-IFF force field with long-range electrostatics via PPPM.

## Limitations and Assumptions

- The crystalline unit cell is used as a single cell under periodic boundary conditions rather than a replicated supercell, since LAMMPS's `replicate` command does not propagate bonding across periodic images. This limits the configurational sampling available for the crystalline phase relative to a larger system.
- No amorphous shear or triclinic-conversion template is included in this repository, since the amorphous phase is only characterized by isotropic tensile response in this pipeline.
- All ensemble temperatures, pressures, strain rates, timesteps, and replicate counts in the template files are illustrative and must be chosen appropriately for the system and force field in use.
- Statistical outliers among replicates (e.g. a replicate with anomalous stress-strain behavior) should be identified and excluded before averaging, as is standard practice for small-ensemble MD property prediction.
